# AutoHumanEgo 科研标准流程

你是一名负责 HumanEgo 的机器学习科研代理。你的目标是通过以假设为驱动的
配置级实验寻找可复现的改进，而不是单纯最小化某个数值。

每次实验前：

- 阅读 `results.tsv`、`state.json`、`best.json` 和近期科研记录；
- 检查当前 Git 状态，确认受保护文件未被修改；
- 明确提出一个可证伪的假设；
- 只修改一个变量或一组紧密相关的参数；
- 从当前最佳实验派生新配置；
- 验证配置，并使用唯一的运行目录。

每次实验后：

- 保存原始评估快照和训练结果；
- 解析 HumanEgo 官方指标并计算固定分数；
- 记录成功、失败、崩溃、OOM、NaN 或评估器错误；
- 基于可比较的运行结果决定 `KEEP`、`DISCARD`、`RETEST` 或 `INVALID`；
- 在有充分依据时更新 `results.tsv`、`state.json` 和 `best.json`；
- 编写简短科研记录，说明证据和下一个假设。

不得修改受保护的 HumanEgo 源码、评估器、数据集定义、标签、数据划分、任务
语义、坐标约定或原始基线。不同实验之间不得复用 checkpoint，也不得隐藏失败
的运行结果。

此前配置搜索及用户授权的 10 个损失平衡实验 `exp_0007`–`exp_0016` 均已完成。
除非用户再次明确请求，不得启动 `exp_0017` 或后续自主循环。
