# exp_0009 —— open_door w_g 损失平衡实验

### 观察

当前 best 为 `exp_0006`，score 为 `0.2232099552`，抓取 F1 为 `0.6942704167`。
`exp_0007` 的 `w_rot=1.5` 和 `exp_0008` 的 `w_pos=7.5` 均未改善总分；目前
没有失败实验。

### 假设

在冻结其他训练超参数、损失权重、数据、模型架构、seed、预算和评估协议时，将 `w_g`
从 `10.0` 提高到 `15.0`，可能强化抓取监督、提高抓取 F1，并降低总 score。

### 变更

从当前 best `exp_0006` 派生，仅修改：

```text
w_g: 10.0 -> 15.0
```

固定使用 20 epochs、`data_num=1`、seed 7、相同显式训练/验证路径和官方评估协议。

### 预期

- 训练和评估成功完成；
- `grasp_f1_w` 和 `score` 改善；
- 不出现 OOM、NaN、训练崩溃或评估错误。

### 结果

实验已成功完成。

- 状态：`SUCCESS`
- 运行时长：`315.82` 秒
- 训练：295 个样本（`data_num=1`），20 epochs
- 评估：314 帧
- 最终快照：`runs/open_door/autoresearch/exp_0009/eval_snapshots/eval_ep_0020.json`
- `pos_err_w_m`：`0.0902209239`
- `rot_err_w_deg`：`21.6137714667`
- `grasp_f1_w`：`0.7015332259`
- `score`：`0.2362053160`

相较 current best `exp_0006` 的 `0.2232099552`，score 增加约 `5.8%`。训练无 CUDA
OOM、NaN、崩溃或评估缺失。

### 决策

`DISCARD`：`w_g=15.0` 虽提高抓取 F1 并降低位置误差，但旋转误差上升导致总 score
变差；`best.json` 保持为 `exp_0006`。

### 解读

本次结果说明单独强化抓取损失会改变指标权衡，当前 `w_g=10.0` 在官方综合 score
下更优。抓取 F1 的局部改善不足以抵消旋转误差损失。
