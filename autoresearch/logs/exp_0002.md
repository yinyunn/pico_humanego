# exp_0002 —— open_door weight_decay 实验

### 观察

当前 best 为 `exp_0001`：`lr=2e-4`、`weight_decay=0.01`，search budget 下的
score 为 `1.2493927171`。目前没有失败实验；基线 smoke 与 search 实验均成功。

### 假设

在保持学习率、数据、模型、seed、训练预算和评估协议不变时，将 `weight_decay`
从 `0.01` 降到 `0.0`，可能减少当前小数据短预算下的正则化偏差，从而降低 score。

### 变更

从当前 best `exp_0001` 派生，仅修改：

```text
weight_decay: 1.0e-2 -> 0.0
```

固定使用 20 epochs、`data_num=1`、seed 7、相同显式训练/验证路径和官方评估协议。

### 预期

- 训练和评估成功完成；
- `score` 低于当前 best `1.2493927171`；
- 不出现 OOM、NaN、训练崩溃或评估错误。

### 结果

实验已成功完成。

- 状态：`SUCCESS`
- 运行时长：`323.40` 秒
- 训练：295 个样本（`data_num=1`），20 epochs
- 评估：314 帧
- 最终快照：`runs/open_door/autoresearch/exp_0002/eval_snapshots/eval_ep_0020.json`
- `pos_err_w_m`：`0.2689031462`
- `rot_err_w_deg`：`103.4530022538`
- `grasp_f1_w`：`0.4605866884`
- `score`：`1.2573744999`

相较当前 best `exp_0001` 的 `1.2493927171`，score 增加约 `0.64%`。训练无 CUDA
OOM、NaN、崩溃或评估缺失。

### 决策

`DISCARD`：在本次固定短预算和数据协议下，去除 weight decay 没有改善 score；
`best.json` 保持为 `exp_0001`。

### 解读

当前证据不支持 `weight_decay=0.0` 优于 `0.01`。该结论仅适用于一个 seed、20 epoch
和 `data_num=1` 的短预算，不能推断完整训练预算下的最终表现。
