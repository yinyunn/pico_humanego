# exp_0008 —— open_door w_pos 损失平衡实验

### 观察

当前 best 为 `exp_0006`，score 为 `0.2232099552`，位置误差为 `0.0995766305 m`。
此前尚未改变位置损失权重；`exp_0007` 提高 `w_rot` 后 score 变差，已判定为
`DISCARD`。

### 假设

在冻结其他训练超参数、损失权重、数据、模型架构、seed、预算和评估协议时，将 `w_pos`
从 `5.0` 提高到 `7.5`，可能降低位置误差，同时不显著损伤旋转误差和抓取 F1，进而
降低总 score。

### 变更

从当前 best `exp_0006` 派生，仅修改：

```text
w_pos: 5.0 -> 7.5
```

固定使用 20 epochs、`data_num=1`、seed 7、相同显式训练/验证路径和官方评估协议。

### 预期

- 训练和评估成功完成；
- `pos_err_w_m` 和 `score` 下降；
- 不出现 OOM、NaN、训练崩溃或评估错误。

### 结果

实验已成功完成。

- 状态：`SUCCESS`
- 运行时长：`343.91` 秒
- 训练：295 个样本（`data_num=1`），20 epochs
- 评估：314 帧
- 最终快照：`runs/open_door/autoresearch/exp_0008/eval_snapshots/eval_ep_0020.json`
- `pos_err_w_m`：`0.1104936420`
- `rot_err_w_deg`：`24.1581394680`
- `grasp_f1_w`：`0.6524450049`
- `score`：`0.2868305362`

相较 current best `exp_0006` 的 `0.2232099552`，score 增加约 `28.5%`。训练无 CUDA
OOM、NaN、崩溃或评估缺失。

### 决策

`DISCARD`：提高 `w_pos` 未改善位置误差，且旋转误差和抓取 F1 也不利；`best.json`
保持为 `exp_0006`。

### 解读

本次结果不支持简单提高位置损失权重。在当前已关闭 EMA 和学习率调度的配置下，
`w_pos=5.0` 优于 `7.5`；该结论仍限于单 seed 和短预算。
