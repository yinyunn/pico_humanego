# exp_0005 —— open_door EMA 实验

### 观察

当前 best 为 `exp_0003`：`lr=2e-4`、`grad_clip=2.0`、`dropout=0.05`、`use_ema=True`，
20 epoch search score 为 `1.2488108507`。`exp_0002` 和 `exp_0004` 已分别因 score
变差而被淘汰；目前没有失败实验。

### 假设

在保持当前 best 的其他配置、数据、模型、seed、训练预算和评估协议不变时，关闭 EMA
可能避免短预算末端的参数平滑滞后，使最终模型更贴合最新优化状态并降低 score。

### 变更

从当前 best `exp_0003` 派生，仅修改：

```text
use_ema: True -> False
```

固定使用 20 epochs、`data_num=1`、seed 7、相同显式训练/验证路径和官方评估协议。

### 预期

- 训练和评估成功完成；
- `score` 低于当前 best `1.2488108507`；
- 不出现 OOM、NaN、训练崩溃或评估错误。

### 结果

实验已成功完成。

- 状态：`SUCCESS`
- 运行时长：`302.84` 秒
- 训练：295 个样本（`data_num=1`），20 epochs
- 评估：314 帧
- 最终快照：`runs/open_door/autoresearch/exp_0005/eval_snapshots/eval_ep_0020.json`
- `pos_err_w_m`：`0.1115425875`
- `rot_err_w_deg`：`23.9391639699`
- `grasp_f1_w`：`0.6437400694`
- `score`：`0.2865602202`

相较 `exp_0003` 的 `1.2488108507`，score 降低约 `77.1%`；位置误差、旋转误差和
抓取 F1 均同步改善。训练无 CUDA OOM、NaN、崩溃或评估缺失。

### 决策

`KEEP`：实验条件与当前 best 可比，`exp_0005` 成为新的当前 best。

### 解读

在当前单 seed、20 epoch 和 `data_num=1` 条件下，关闭 EMA 产生了大幅改善，这是本批
目前最强的初步证据。但该提升仍可能依赖短预算末端的 EMA 与即时权重差异，必须在更长
预算和多 seed 下复现后，才能形成稳健结论。
