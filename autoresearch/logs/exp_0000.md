### 变更

未修改模型、数据集、评估器、预处理、推理、数据划分或任务定义。创建基线配置
副本 `cfg/training/open_door/autoresearch/exp_0000.yaml`，显式引用真实的
open_door 数据路径，并使用仅用于冒烟测试的运行时覆盖参数：

```text
--epochs 1 --data_num 1 --num_workers 0 --device cuda --seed 7
```

训练器会在加载 YAML 后根据 CLI 参数重置 `data_paths_explicit`，因此
`run_experiment.py` 会将配置中的显式路径转发为真实的 `--train_data` 和
`--eval_data` 参数。这是针对实际 Trainer CLI 的基础设施适配，不涉及受保护源码。

为了缩短 smoke 时间，本次额外使用 `--data_num 1`，只训练第一个训练 session；
完整配置仍保留全部 29 个训练路径。

实际执行命令：

```bash
conda run -n humanego python -m training.FlowMatchingTrainer \
  --task open_door --use_cfg --exp autoresearch --job exp_0000 \
  --epochs 1 --data_num 1 --num_workers 0 --device cuda --seed 7
```
