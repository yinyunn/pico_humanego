# exp_0006 —— open_door 学习率调度实验

### 观察

当前 best 为 `exp_0005`：`lr=2e-4`、`grad_clip=2.0`、`dropout=0.05`、`use_ema=False`，
20 epoch search score 为 `0.2865602202`。此前 `weight_decay=0.0` 和 `dropout=0.0`
被淘汰，`grad_clip=2.0` 和关闭 EMA 被保留；目前没有失败实验。

### 假设

在保持当前 best 的其他配置、数据、模型、seed、训练预算和评估协议不变时，关闭学习率
调度可能使学习率在短预算内保持更高水平，增强后期适应能力并进一步降低 score。

### 变更

从当前 best `exp_0005` 派生，仅修改：

```text
use_lr_schedule: True -> False
```

固定使用 20 epochs、`data_num=1`、seed 7、相同显式训练/验证路径和官方评估协议。

### 预期

- 训练和评估成功完成；
- `score` 低于当前 best `0.2865602202`；
- 不出现 OOM、NaN、训练崩溃或评估错误。

### 结果

实验已成功完成。

- 状态：`SUCCESS`
- 运行时长：`312.37` 秒
- 训练：295 个样本（`data_num=1`），20 epochs
- 评估：314 帧
- 最终快照：`runs/open_door/autoresearch/exp_0006/eval_snapshots/eval_ep_0020.json`
- `pos_err_w_m`：`0.0995766305`
- `rot_err_w_deg`：`19.3060366368`
- `grasp_f1_w`：`0.6942704167`

相较 `exp_0005` 的 `0.2865602202`，score 降低约 `22.1%`；位置误差、旋转误差和
抓取 F1 均改善。训练无 CUDA OOM、NaN、崩溃或评估缺失。

### 决策

`KEEP`：实验条件与当前 best 可比，`exp_0006` 成为新的当前 best。本实验完成后
停止本批次，不启动 `exp_0007`。

### 解读

在关闭 EMA 的基础上关闭学习率调度，在本次固定 seed、20 epoch 和 `data_num=1`
条件下进一步改善了所有核心评估指标。该结果支持“短预算内保持 `lr=2e-4` 有利于
当前数据设置”的初步假设，但仍需独立 seed 和更长预算验证。
