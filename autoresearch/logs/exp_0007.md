# exp_0007 —— open_door w_rot 损失平衡实验

### 观察

当前 best 为 `exp_0006`，score 为 `0.2232099552`。其旋转误差为 `19.3060°`，在
固定 score 中占据重要贡献；此前尚未进行损失平衡搜索，也没有失败实验。

### 假设

在冻结所有非损失训练超参数、数据、模型架构、seed、预算和评估协议时，将 `w_rot`
从 `1.0` 提高到 `1.5`，可能降低旋转误差并改善总 score。

### 变更

从当前 best `exp_0006` 派生，仅修改：

```text
w_rot: 1.0 -> 1.5
```

固定使用 20 epochs、`data_num=1`、seed 7、相同显式训练/验证路径和官方评估协议。

### 预期

- 训练和评估成功完成；
- `rot_err_w_deg` 和 `score` 下降；
- 不出现 OOM、NaN、训练崩溃或评估错误。

### 结果

实验已成功完成。

- 状态：`SUCCESS`
- 运行时长：`342.78` 秒
- 训练：295 个样本（`data_num=1`），20 epochs
- 评估：314 帧
- 最终快照：`runs/open_door/autoresearch/exp_0007/eval_snapshots/eval_ep_0020.json`
- `pos_err_w_m`：`0.1021131374`
- `rot_err_w_deg`：`20.4855702819`
- `grasp_f1_w`：`0.6724186919`
- `score`：`0.2397269710`

相较 current best `exp_0006` 的 `0.2232099552`，score 增加约 `7.4%`。训练无 CUDA
OOM、NaN、崩溃或评估缺失。

### 决策

`DISCARD`：`w_rot=1.5` 虽然旋转误差方向上接近预期，但位置误差和抓取 F1 的变化
使总 score 变差；`best.json` 保持为 `exp_0006`。

### 解读

在当前损失平衡下，单独提高旋转损失权重没有带来净收益，说明 score 中旋转项的表面
贡献不能直接决定最优训练损失权重。
